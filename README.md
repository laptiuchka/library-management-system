# Система управління бібліотекою (Library management system)

Навчальний веб-застосунок для управління бібліотечним фондом та користувачами, розроблений за допомогою TypeScript з дотриманням принципів ООП, Generics та Namespaces.

## Функціонал
- **Керування книгами**: додавання нової книги (з валідацією полів та року), видалення, статус доступності.
- **Керування користувачами**: додавання читачів із валідацією обов'язкових полів та email, числовий ідентифікатор (ID).
- **Позичання та повернення**: ліміт не більше 3 книг на одного користувача, кастомні модальні вікна замість системних `alert()`.
- **Пошук та пагінація**: фільтрація книг за назвою/автором, розбиття списків на сторінки по 5 елементів.
- **Збереження стану**: автоматична синхронізація з `LocalStorage`.

## Технологічний стек
- **Мова**: TypeScript
- **Збирачі проєктів**: Webpack (гілка `main`), Vite (гілка `vite-migration`).
- **Стилі**: Bootstrap 5, SCSS.
- **Лінтер та форматування**: ESLint, Prettier.
- **Git Hooks**: Husky (для автоматичного запуску лінтера та тестів перед комітом).
- **Тестування**: Mocha, Chai, ts-node (11 unit-тестів).
- **Деплой**: GitHub Pages (`gh-pages`).
